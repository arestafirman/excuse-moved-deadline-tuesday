## Entry

> I didn't miss the deadline — I moved it to next Tuesday in your calendar, and your calendar believed me.

## How it works

`main.ts` is a dependency-free Node program. It writes the one-line excuse above, byte-for-byte, to `entry.txt` inside the output directory (from the `OUTPUT_DIR` environment variable, default `/output`). No network, no clock, no randomness — the output is fully deterministic.
